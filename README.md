## 关于本项目 / About

竹 Digital 是一个面向澳大利亚华人小企业主的合规信息网站，提供 ABN 注册、GST 申报、Fair Work 雇员合规、超级年金、账本记录及海外收入等方面的中英文指引。

This is a bilingual (Chinese/English) compliance information website for Chinese-Australian small business owners, covering ABN, GST & BAS, Fair Work, Superannuation, Record Keeping, and Overseas Income topics.
